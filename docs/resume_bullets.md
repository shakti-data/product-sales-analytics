# Resume bullets — Retail Sales Analytics

- Built a Bronze-Silver-Gold data warehouse in SQL Server from 6 CRM/ERP source files, modelled as a star schema (1 fact, 2 dimensions) covering 18,482 customers and 60,398 sales rows.
- Wrote T-SQL analytics using CTEs and window functions (running totals, year-over-year, segmentation) and built customer and product report views.
- Used Python (pandas, SciPy) for RFM segmentation, cohort retention, Pareto and hypothesis testing. Found that 2 customer segments drive about 96% of revenue.
- Delivered an Excel report and a Power BI dashboard for sales and product performance.
